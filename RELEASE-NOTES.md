Kitaplığım'ın ilk GitHub sürümü. Uygulama sürümü: **2.4.0**.

- **Yerel kullanım:** ZIP'i çıkar ve Windows'ta `BASLAT.cmd`, Linux/macOS'ta `python3 baslat.py` ile aç. Python 3 gerekir.
- **Docker sunucusu:** Repoyu klonla ve `docker compose up -d --build` çalıştır. Veri dizinini değiştirmeden sonraki sürümler için `bash scripts/update-linux.sh` kullan.
- PDF/EPUB okuyucu, kaldığın yer, görünmez okuma süresi takibi, ay/yıl bazlı biten kitap listesi, sayfa sayısı düzeltme ve tür yönetimi dahildir.
- Mevcut Docker kurulumundan geçerken README'deki veri dizini adımlarını izle.
